# 会务领域模型

本参考对齐 RFC-0001。Agent 可以把这些内容用于澄清和解释，但最终冲突、规则、组合空间和状态版本必须以 FastAPI 返回为准。

## 固定空间关系

- 默认查询空间包含：活动室、会议室一、会议室二、503、505、506；
- 503、505、506 是小会议室；
- 505 每周二全天不可用；
- 活动室午餐时段不可预约；
- 会议室一、会议室二可以合并为组合空间；
- 创建组合预约后，成员房间不能再被分别预约；
- 504 是动态禁用和平面图演示房间，不是默认小会议室关系；
- 502 不作为默认房间或可用结果。

## 规则与预约

- 规则由后端领域服务统一维护；
- 预约由后端统一做冲突校验；
- 组合空间约束由后端判断；
- 临时禁用、午餐规则、周二不可用等都必须通过规则引擎解释；
- Agent 不硬编码最终可预约结果，只展示 FastAPI 返回的候选、排除原因和冲突详情。

## 状态版本

- 后端响应包含 `meta.state_revision`；
- 所有写操作必须提交 `expected_state_revision`；
- 遇到 `STATE_REVISION_CONFLICT` 时，Agent 必须展示当前 revision、影响摘要，并请求用户再次确认；
- 工具不得伪造 revision，也不得静默覆盖冲突。
