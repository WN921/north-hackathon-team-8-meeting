# 领域结果

本目录对应 RFC-0001，用于沉淀会务系统领域模型与规则引擎结果。

## 必须覆盖的领域能力

- 房间：活动室、会议室一、会议室二、503、505、506；
- 组合空间：会议室一+会议室二；
- 固定规则：活动室午餐不可预约、505 周二全天不可用；
- 动态规则：临时维修、活动占用、维护等；
- 预约：创建、取消、修改、冲突检测；
- 状态版本：每次成功写入后单调递增；
- 规则连续修改：同一业务意图更新同一条规则。
